# BakeSmart.ua
Project for web design and development lab course featuring baking calculator and recipe catalog.

# BakeSmart.ua: форма зворотного зв'язку

Лабораторна робота №9: адаптивна форма (HTML5 + Tailwind CSS) із клієнтською валідацією (Vanilla JS).

## Проєкт
Українська платформа для випічки: рецепти, точні пропорції та зручні сервіси для домашніх кондитерів.

## Структура
- `index.html`: лендинг, форма `#feedbackForm` і модальне вікно `#successModal`
- `css/style.css`: стилі та UI-стани (normal / focus / error / success)
- `assets/js/validation.js`: RegEx, функції валідації, керування станами, submit

## Правила валідації форми
| Поле | Правило |
|---|---|
| Ім'я | 2–50 символів, мінімум 2 літери, без цифр і спецсимволів |
| Email | Коректний формат `user@domain.tld` |
| Телефон | Формат `+380` і рівно 9 цифр (`0501234567` автоматично приводиться до `+380501234567`) |
| Повідомлення | Не менше 10 символів |
| Згода | Обов'язково `checked` |

## Примітка
Дані нікуди не надсилаються на сервер: це імітація успішного надсилання після успішного проходження клієнтської валідації.
