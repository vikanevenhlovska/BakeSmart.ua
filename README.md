Project for web design and development lab course featuring baking calculator and recipe catalog.

# BakeSmart.ua: форма зворотного зв'язку

Лабораторна робота №9: адаптивна форма (HTML5 + Tailwind CSS) із клієнтською валідацією (Vanilla JS).

## Проєкт
Українська платформа для випічки: рецепти, точні пропорції та зручні сервіси для домашніх кондитерів.

## Структура
- `index.html`: лендинг, форма `#feedbackForm` і модальне вікно `#successModal`
- `css/style.css`: стилі та UI-стани (normal / focus / error / success)
- `assets/js/validation.js`: RegEx, функції валідації, керування станами, submit
- `assets/js/widget.js`: логіка калькулятора форм (ЛР №11)

## Правила валідації форми
| Поле | Правило |
|---|---|
| Ім'я | 2–50 символів, мінімум 2 літери, без цифр і спецсимволів |
| Email | Коректний формат `user@domain.tld` |
| Телефон | Формат `+380` і рівно 9 цифр (`0501234567` автоматично приводиться до `+380501234567`) |
| Повідомлення | Не менше 10 символів |
| Згода | Обов'язково `checked` |

## Примітка
Дані нікуди не надсилаються на сервер: це імітація успішного надсилання після успішного проходження клієнтської валідації.

# ЛР №11: інтерактивний віджет і Edge Cases

Віджет: **калькулятор пропорцій та форм** (секція `#calculator`). Логіка в `assets/js/widget.js` (Vanilla JS, IIFE без глобальних змінних).

## Параметри, що впливають на результат
| Параметр | Елемент | Значення | Вплив |
|---|---|---|---|
| Режим | кнопки `.modes` | за формою / за порціями | спосіб розрахунку коефіцієнта |
| Тип форми (рецепт і ваша) | `select` | кругла / квадратна / прямокутна | формула площі |
| Розміри форми | `input number` | 5–80 см, крок 0,5 | площа → коефіцієнт |
| Порції (рецепт і потрібно) | `input number` | 1–100, цілі | коефіцієнт = потрібно / у рецепті |

Формула: `коефіцієнт = площа вашої форми / площа форми з рецепта` (або `порції_потрібно / порції_у_рецепті`), кількість інгредієнта = `базова вага × коефіцієнт`.

## Захист (Defensive Programming)
1. HTML5: `type="number"`, `min`, `max`, `step`, `required`.
2. JavaScript: `readNumber()` відсікає порожнє значення, текст, `NaN`, `Infinity`; `inRange()` перевіряє діапазон; дробові порції округлюються до цілих; невідоме значення `select` скидається до «Кругла»; весь розрахунок у `try/catch`; якщо потрібного DOM-елемента немає, віджет вимикається з попередженням у консоль.
3. Безпечний вивід: результат формується через `textContent` / `createElement`, без `innerHTML`.
4. UI: помилка під полем (`aria-describedby`, `aria-invalid`), червона рамка `!border-red-500` (Tailwind), підсумкове повідомлення в `#err`.
